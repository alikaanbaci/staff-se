# This Site

**Tech stack:** Docusaurus · React · TypeScript · GitHub Actions

This site is itself a project: a navy-themed engineering blog and personal
portfolio built on Docusaurus, with Turkish/English (i18n) support.

## Highlights

- **i18n:** Turkish (default) and English language support, switchable from
  the locale dropdown in the top-right corner.
- **Projects section:** the project showcase you're reading right now, built
  on top of Docusaurus's docs plugin.
- **Engineering blog:** under `/blog`, with RSS/Atom feed support.
- **GitHub Pages CI/CD:** automatic build & deploy via GitHub Actions on every
  push to `main`.

## Source code

The site's source code lives in this repository itself — check out
`docusaurus.config.ts`, `projects/`, `blog/` and `src/`.
