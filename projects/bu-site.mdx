# Bu Site

**Teknolojiler:** Docusaurus · React · TypeScript · GitHub Actions

Bu sitenin kendisi de bir proje: Docusaurus üzerine kurulmuş, Türkçe/İngilizce
(i18n) destekli, lacivert temalı bir mühendislik blogu ve kişisel portföy.

## Öne çıkan özellikler

- **i18n:** Türkçe (varsayılan) ve İngilizce dil desteği, sağ üstteki dil
  seçiciden değiştirilebilir.
- **Projeler bölümü:** Bu sayfanın da içinde bulunduğu, Docusaurus'un docs
  eklentisi üzerine kurulu proje vitrini.
- **Mühendislik blogu:** `/blog` altında RSS/Atom feed desteğiyle birlikte.
- **GitHub Pages CI/CD:** `main` dalına her push'ta GitHub Actions ile otomatik
  build & deploy.

## Kaynak kod

Sitenin kaynak kodu deponun kendisinde — `docusaurus.config.ts`, `projects/`,
`blog/` ve `src/` klasörlerine göz atabilirsiniz.
